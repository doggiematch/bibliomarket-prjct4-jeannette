Flujos completos para defenderlo oralmente

De extremo a extremo
1RegistroSe crea User, se hashea password con bcrypt y se devuelve token.
2LoginSe comparan credenciales y el frontend guarda token y user en localStorage.
3ExplorarGET /api/books usa filtros, búsqueda y optionalAuth para personalizar resultados.
4Crear libroBookForm puede autocompletar con Open Library y envía POST /api/books.
5ReservarSe crea Reservation y el libro pasa de AVAILABLE a RESERVED.
6Mi bibliotecaPromise.all carga mis libros, reservas, favoritos y géneros para gestionarlo todo.

Cómo se defiende la base

Idea central 
Bibliomarket es full stack porque cada acción visible tiene recorrido completo:

React detecta la acción del usuario
→ Fetch llama a Express
→ Middleware comprueba token y validaciones
→ Controlador aplica reglas de negocio
→ Prisma modifica PostgreSQL
→ La respuesta actualiza la interfaz

Ejemplo: al reservar un libro, no solo se añade una fila en Reservation.
También se cambia el estado del Book para que deje de aparecer como disponible.
