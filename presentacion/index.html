Quién soy + qué es Bibliomarket

J

Jeannette

Alumna del bootcamp. Proyecto 4 centrado en backend, con una semana intensiva de desarrollo full stack.

Problema

Libros de segunda mano sin una forma sencilla de circular entre particulares.

Solución

Retos + reflexión final

Mayor reto

Integrar el flujo completo: frontend, backend, JWT, base de datos y despliegue de forma coherente y funcional.

Gestionar estados reales del usuario: libros propios, favoritos, reservas, errores y rutas protegidas.

Adaptar el modelo de datos para que reservas, favoritos y estados de libro funcionaran de forma coherente.
